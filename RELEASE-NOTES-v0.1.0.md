## TabJev v0.1.0

TabJev sorts new tabs into your Chrome tab groups automatically, asking Jev
(TypeSafe) which group each tab belongs to instead of running an LLM chat
completion on every tab. Requires your own Jev API key — get one at
console.typesafe.ai.

### Install

1. Download `tabjev-v0.1.0.zip` below and unzip it.
2. `chrome://extensions` → enable Developer mode.
3. "Load unpacked" → select the unzipped folder.

### Not there yet

No Chrome Web Store build, no per-domain exclusions, and no automatic
ungroup-on-close.
